# tech-notes (English)

A personal repository for technical notes on how to use Claude and GitHub.

Notes are gradually written into Markdown / PowerPoint files by asking Claude questions along the way. Japanese is the primary reading material; the `.en.md` files are Markdown translations kept around for sharing with others.
